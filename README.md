# Pájaro Azul - Landing Page Premium

Landing page elegante y cálida para **Pájaro Azul**, elaboradores artesanales de **Bondiola Curada** en Mendoza, Argentina.

## Características

*   **Identidad Visual Premium:** Paleta de colores cálida inspirada en la gastronomía rural (crema, madera, marrón suave y azul corporativo).
*   **Diseño 100% Responsivo:** Adaptado para celulares, tabletas y computadoras de escritorio.
*   **Interacciones Dinámicas:**
    *   Navegación fluida por secciones (Smooth Scroll).
    *   Galería interactiva con Lightbox nativo (apertura a pantalla completa y navegación).
    *   Efecto Sticky Navbar y detector de secciones activas.
    *   Animaciones de entrada al hacer scroll (`IntersectionObserver`).
*   **Ambiance de Campo:** Fotografías de alta calidad generadas específicamente para contextualizar el producto en un entorno rústico y casero.
*   **Integración Directa con WhatsApp:** Botón de contacto directo con mensaje predefinido para pedidos y consultas.

## Tecnologías Utilizadas

*   HTML5 (Estructura semántica y metatags SEO).
*   CSS3 (Variables, Flexbox, Grid, keyframe animations, glassmorphism).
*   JavaScript (ES6, modular).
*   Vite (Servidor de desarrollo y constructor de producción).

## Desarrollo Local

1.  Instalar dependencias:
    ```bash
    npm install
    ```
2.  Correr servidor de desarrollo:
    ```bash
    npm run dev
    ```
3.  Compilar para producción:
    ```bash
    npm run build
    ```
